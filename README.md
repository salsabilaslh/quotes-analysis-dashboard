# 📊 Quotes Analysis Dashboard

An interactive web-based dashboard project developed as part of a Spring 2026 midterm project.

This application allows users to explore, search, analyze, and translate quote datasets through an interactive dashboard interface built with Python and Gradio.

---

## Features

* View and manage quote datasets
* Search quotes by keyword
* Real-time translation

  * Korean translation
  * Indonesian translation
* Dashboard analytics

  * Total quotes
  * Total authors
  * Average word count
  * Longest & shortest quotes
* Random quote generator
* Author visualization chart
* SQLite database integration
* Web scraping automation

---

## ⚙️ How It Works

The application automatically collects quote data through web scraping and stores it in a SQLite database.
Users can interact with the dashboard to search quotes, analyze datasets, generate visualizations, and translate quotes into multiple languages using external translation APIs.

The dashboard interface is developed using Gradio for interactive web-based user experience.
